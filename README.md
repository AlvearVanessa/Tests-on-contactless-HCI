# Tests-on-contactless-HCI
Four pilot projects exploring vision-based, contactless **Human-Computer Interaction (HCI)** using real-time hand, pose, face detection, and face mesh tracking.

### 🚀 Pilot Projects

* **Gesture Volume Control:** Gesture-based audio control module.
* **Finger Counter:** Real-time hand landmark and digit detection.
* **Burger Machine Interface:** Contactless touchless ordering kiosk.
* **3D Hand Tracking:** Physics-driven interaction within a virtual environment.

### 🛠 Tech Stack

* **Computer Vision:** Python, Google MediaPipe, OpenCV, CvZone
* **3D Engine & Logic:** Unity 3D, C#
